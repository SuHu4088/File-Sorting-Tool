# 文件分类整理工具

## 项目简介

这是一个基于 Python + Tkinter 的文件整理工具。
程序会读取源目录中的子文件夹（命名模板通常为 `%USER_SCREEN_NAME%,%USER_NAME%,%POST_TIME%`），提取第一个逗号前的用户名，把子文件夹内文件归并到目标目录对应的用户名文件夹，并在完成后删除已处理子文件夹。

## 主要功能

- 自动按用户名归类文件（从子文件夹名称提取用户名）。
- 递归提取并移动子文件夹中的文件。
- 自动处理重名文件（追加 `_1`、`_2`...）。
- 自动清理文件名中的非法字符（提高跨平台兼容性）。
- GUI 选择源目录/目标目录，暗色主题，居中显示。
- 完成后显示统计信息（移动文件数、清理文件夹数、跳过项目数）。

## 运行环境

- Python 3.8+
- tkinter（大多数 Python 发行版已内置）

## 使用方式

```bash
python file_sorting_tool.py
```

运行后：

1. 选择源文件夹。
2. 选择目标文件夹。
3. 点击“开始整理”。

## 开发建议

- 新功能优先修改 `file_sorting_tool.py`。
- `V1.x` 文件建议仅作历史参考，不再作为主入口维护。
- 如果需批处理/自动化，可在后续增加 CLI 参数模式（无 GUI）。
